# 第二轮创新优化预审对照表

日期：2026-07-30  
用途：核对第二版是否针对第一轮审查扣分项形成实质性改进

## 一、预计评分

| 专利 | 第一版 | 第二版预估 | 主要提升来源 | 第二版结论 |
|---|---:|---:|---|---|
| 双指纹契约原子升级 | 84 | **91** | 从静态接口清单升级为目标硬件动态行为验证，并增加张量代次和状态污染边界 | 优先申请 |
| 不可补偿场景证书安全切换 | 82 | **90** | 从综合评分放行升级为逐关键场景证书和一次性可撤销路由许可 | 优先申请 |
| 跨窗口预热与状态租约激活 | 74 | **87** | 避开停车概率选时，保护跨窗口工件复用和陈旧许可自动失效 | 修改后可申请 |

上述分数是申请前模拟评分，不是授权承诺。

## 二、第一版问题与第二版闭环

| 第一版问题 | 第二版技术机制 | 对应技术效果 |
|---|---|---|
| 静态接口一致仍可能运行失败 | 目标硬件执行探针并生成动态指纹 | 发现驱动、算子、量化和状态行为不兼容 |
| 共享张量可能跨版本误用 | 骨干、预处理和状态三重代次快照 | 阻断陈旧或语义变化张量 |
| 局部回滚可能遗留共享状态 | 实际内存写集形成状态污染边界 | 回滚真实受污染对象并保留无关对象 |
| 总体指标掩盖关键场景 | 关键场景通过位图不可补偿 | 任一关键场景失败即不签发许可 |
| 风险评分需要二次解释 | 一次性、可撤销切主许可 | 路由控制器可直接校验和立即撤销 |
| 原始回放数据隐私风险 | 不可逆隐私回放胶囊 | 减少原始音视频持久化 |
| 停车概率选时已有授权 | 跨窗口预热工件和状态租约 | 保护模型生命周期状态延续而非时间推荐 |
| 预热判断在激活时过期 | 激活租约及状态新鲜度二次门控 | 阻止基于陈旧车况的版本切换 |
| 下载断点不能复用编译结果 | 硬件绑定预热工件 | 跨窗口复用编译、映射和试推理结果 |

## 三、三项专利的最终技术边界

1. 专利一回答“哪些模型对象在当前硬件上真实兼容，哪些对象必须共同升级或回滚”。
2. 专利二回答“候选模型是否已经取得覆盖关键场景的放行证据，能否获得或继续持有业务控制权”。
3. 专利三回答“升级阶段如何跨多个车辆窗口延续，何时因状态过期停止，如何在激活前重新取得新鲜许可”。

## 四、第二版仍需申请人提供的材料

1. 目标座舱芯片、NPU 驱动、推理运行时和模型格式。
2. 一个真实的共享骨干与任务头张量接口示例。
3. 动态探针在静态接口匹配情况下发现异常的测试记录。
4. DMS、语音或手势模型至少一组关键场景划分和历史指标。
5. 一次候选模型灰度后回滚的实际日志或模拟日志。
6. 大型模型下载、编译、映射和试推理各阶段耗时。
7. 至少三个不连续停车窗口的升级过程数据。

## 五、正式申请前建议

1. 第一、第二项可作为同一批次提交，但说明书和权利要求不得互相混入对方核心。
2. 第三项不再把用户画像作为独立权利要求的首要特征，可将隐私画像留作从属项或分案储备。
3. 为三项分别制作“最接近现有技术—区别特征—实际技术问题—技术效果”四列表。
4. 以实测数据替换详细稿中的纯示例参数，避免审查中只能主张理论效果。
5. 正式提交文本应补充摘要、摘要附图、说明书附图编号和系统/设备/存储介质权利要求。
